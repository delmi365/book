# 附录 A · 三十天自我建设路线图

这份路线图的设计原则只有两个：**每天都有具体动作**，以及**总共不超过四十五分钟**。任何需要"每天三小时"的计划都会在第二周死掉。

## 第一周：地基（先把身体和作息固定下来）

| 天 | 动作 |
| --- | --- |
| 第 1 天 | 定一个起床时间（比现在早半小时），之后三十天不改变。写下你的一页纸（第八章的练习）。 |
| 第 2 天 | 剪头发，找一个固定的理发师。晚上把衣柜里起球、变形、明显不合身的衣物挑出来扔掉。 |
| 第 3 天 | 买护肤三件套（洁面、保湿、防晒），当晚开始用。 |
| 第 4 天 | 第一次训练：只做深蹲、卧推、划船，轻重量，学动作。 |
| 第 5 天 | 记账。把过去一个月的收入和支出列出来，标出"说不清花在哪"的部分。 |
| 第 6 天 | 走路时注意姿态：沉肩、挺胸、不低头看手机。全天执行。 |
| 第 7 天 | 复盘：这周起床时间做到了几天？写下下周要修的一个人。 |

## 第二周：形象与财务（把可见的部分修好）

| 天 | 动作 |
| --- | --- |
| 第 8 天 | 第二次训练（加硬拉、肩推）。 |
| 第 9 天 | 预约洗牙，或至少去买一支牙线并当天用。 |
| 第 10 天 | 拍一张全身照作为基准，存在一个专门的相册里。 |
| 第 11 天 | 列出衣橱缺口清单（对照第五章的基础配置表或附录 C1）。 |
| 第 12 天 | 设立"安全垫"账户，转入第一笔钱（哪怕是 500 元）。 |
| 第 13 天 | 第三次训练。修眉毛与胡须。 |
| 第 14 天 | 复盘：连续两周早起做到了几天？本周有没有因为情绪而影响别人？ |

## 第三周：场景与社交（把人放进结构里）

| 天 | 动作 |
| --- | --- |
| 第 15 天 | 列出你现在的活动场景清单，标出哪些能遇到新面孔。 |
| 第 16 天 | 选一个需要配合的活动报名（球类、舞蹈、训练课、课程班）。 |
| 第 17 天 | 告诉三到五个朋友你在找对象，并且说清你的标准。 |
| 第 18 天 | 第四次训练。固定两三个常去场所与固定时间。 |
| 第 19 天 | 今天至少主动发起一次对话，用"开放且具体"的提问。 |
| 第 20 天 | 补买两件合身的基础件（白衬衫、素色 T 恤或深色裤）。 |
| 第 21 天 | 复盘：这周有没有出现在新场景里？有几次主动开口？ |

## 第四周：输出与起步（从建设转向行动）

| 天 | 动作 |
| --- | --- |
| 第 22 天 | 第五次训练。体态检查：正面、侧面各拍一张照，和第一天对比。 |
| 第 23 天 | 写一段"高分辨率"的自我介绍（不谈标签，只谈具体的事和具体的目标）。 |
| 第 24 天 | 发起一次具体的线下邀约（给出替代方案，不带压力）。 |
| 第 25 天 | 完成本周的"推进动作"：你的三年目标向前挪一步。 |
| 第 26 天 | 第六次训练。晚上做一次独处（一个人散步或待着，不看手机）。 |
| 第 27 天 | 与一位朋友做一次真实交流（见面或通电话，不是发消息）。 |
| 第 28 天 | 填一次附录 B 的自评量表，记录得分。 |
| 第 29 天 | 复盘三十天：哪些动作我做起来毫不费力？哪些每次都要硬撑？ |
| 第 30 天 | 制定下一个三十天计划——只保留你做得下去的动作，砍掉其余。 |

**第 30 天的那句话，是这份路线图最重要的一点：** 判断一个动作要不要保留，标准不是"它有没有用"，而是**"你能不能一直做下去"**。一个能做到三年的 60 分动作，价值远高于一个坚持三周的 100 分动作。

# 附录 B · 自评量表

每三个月填一次。**不要用它给别人打分，也不要把它当成对你的判决——它的唯一用途是帮你看清自己在哪一项上是短板。** 这是一份自我反思用的清单，没有经过心理测量学的信度与效度检验，不具有诊断意义。

## 第一部分：硬价值（每题 0–4 分）

| 序号 | 项目 | 评分 |
| --- | --- | --- |
| 1 | 我每周规律训练三次以上，且已持续三个月 | |
| 2 | 我的体脂率和精力水平处于我自己满意的状态 | |
| 3 | 我的睡眠稳定（固定起床时间，七小时左右） | |
| 4 | 我的姿态、头发、牙齿、气味、皮肤，任何一项都不会让人替我担心 | |
| 5 | 我的衣物合身，配色不超过三色，且不需要每天为穿什么发愁 | |
| 6 | 我有足够的安全垫（至少 3–6 个月的生活开支；收入不稳者 6–12 个月） | |
| 7 | 我有记账习惯，知道自己每月花在哪 | |
| 8 | 我没有用负债维持生活方式 | |
| 9 | 过去一年，我的职业能力有可见的增长 | |
| 10 | 我的收入处于持续上升的轨道上 | |

## 第二部分：软价值（每题 0–4 分）

| 序号 | 项目 | 评分 |
| --- | --- | --- |
| 11 | 我有明确的三年目标，并且每周都有推进动作 | |
| 12 | 我有自己的判断，不需要每件事都问别人 | |
| 13 | 我说到做到，答应的事不会因为心情变化而取消 | |
| 14 | 我的情绪基线稳定，不会因为小事大起大落 | |
| 15 | 我情绪不好时，不会把代价转给身边的人 | |
| 16 | 我能为自己的错误道歉，不找外部原因 | |
| 17 | 在冲突里，我一次只谈一件事 | |
| 18 | 我能接受对话中的沉默，不急着填充 | |
| 19 | 我能在不想做的时候清楚地说"不"，且不过度解释 | |
| 20 | 我每月至少认识一个新的人，或进入一个新场景 | |

## 第三部分：生活系统（每题 0–4 分）

| 序号 | 项目 | 评分 |
| --- | --- | --- |
| 21 | 我有两到五个能说真话的朋友，并且保持实际联系 | |
| 22 | 我至少有一项能累积的爱好，并且坚持了一年 | |
| 23 | 我能一个人待半天而不难受 | |
| 24 | 我有工作之外"属于我自己的作品或项目" | |
| 25 | 我的每周生活有固定结构，不靠意志力维持 | |

## 怎么读分数

- **总分 100 分制。**
- **0–40 分**：现在是建设期。把精力全部放在附录 A 的第一、二周，不要急着进入关系。
- **41–70 分**：地基已经有了。重点放在软价值部分（11–20 题）里得分最低的三项，逐项突破。
- **71–85 分**：你已经处于高价值区间。此时的重点是**扩大场景**与**清晰标准**——认识更多的人，并且想清楚自己真正要什么。
- **86–100 分**：请再检查一遍，是否给自己打得偏宽。自评分数偏高，是很常见的偏差。

**最重要的用法：** 不要看总分，看**最低的五项**。因为关系的短板效应极其明显——你身体练得再好，情绪失控一次就可能毁掉三个月；你财务状况再好，一次越界就会让你失去所有人。

# 附录 C · 速查表

## C1 基础衣橱（二十来件，覆盖大部分日常场景）

| 类别 | 单品 | 数量 |
| --- | --- | --- |
| 上装 | 白色/浅蓝衬衫（合身、纯色） | 3 |
| 上装 | 素色 T 恤（白、灰、藏青） | 5 |
| 上装 | 针织衫/薄毛衣 | 2 |
| 外套 | 深色休闲西装或夹克 | 1–2 |
| 外套 | 大衣（冬季） | 1 |
| 下装 | 深色直筒牛仔裤 | 2 |
| 下装 | 卡其裤/西裤（一深一浅） | 2 |
| 鞋 | 干净的白色运动鞋 | 1 |
| 鞋 | 皮质德比鞋或乐福鞋 | 1 |
| 配件 | 皮带（与鞋同色系）、简洁手表 | 各 1 |

**三条铁律**：合身 > 面料 > 品牌；配色不超过三色；宁少宁好，坏了就换。

## C2 训练速查（每周三到四次，每次 45 分钟）

| 动作 | 组数 | 次数 | 要点 |
| --- | --- | --- | --- |
| 深蹲 / 腿举 | 4 | 6–10 | 膝盖跟脚尖同向 |
| 卧推 / 负重的俯卧撑 | 4 | 6–10 | 肩胛收紧，不弹胸 |
| 硬拉 / 罗马尼亚硬拉 | 3 | 5–8 | 背部中立，重量其次 |
| 划船 / 引体向上 | 4 | 6–12 | 用背发力，不耸肩 |
| 肩推 | 3 | 8–12 | 不借腰 |
| 平板支撑 / 悬垂举腿 | 3 | 40–60 秒 | 腰不塌 |

**进步原则**：每周比上周多一点重量或次数；动作标准优先于重量；连续三个月不停。

## C3 沟通四步表达法

当你不满或者有需求时：

1. **事实**："你昨天说八点回来，实际十一点到。"
2. **感受**："我当时很不安。"
3. **需求**："我希望如果要晚回，你提前告诉我。"
4. **请求**："这样可以吗？"

**禁止词**："你总是""你从不""你根本""你应该早就"。

## C4 冲突五规则

1. 具体化，不用"总是/从不"；
2. 一次只谈一件事；
3. 允许暂停（约定一个暂停信号）；
4. 目标是解决，不是分出对错；
5. 结束前必须有修复动作。

## C5 红旗信号速查

回避问题 · 制造内疚 · 孤立倾向 · 贬低式玩笑 · 极端情绪波动 · 反复试探边界 · 快速建立金钱依赖 · 对所有人负面

出现三条以上：**放慢速度，先弄清楚，不要说服自己。**

# 附录 D · 常见误区五十条

## 关于价值（1–12）

1. 把生存价值等同于收入数字。
2. 用房产、车子去补情绪能力的空缺。
3. 认为"条件比我差的人都有人喜欢"是运气问题。
4. 把"价值"理解为打分，然后把自己和别人都算成分数。
5. 只提升硬价值，从不建设软价值。
6. 认为"我变好了她就会回来"——提升自己从来不是为了挽回谁。
7. 以为吸引力是天赋，不是可积累的能力。
8. 用进化心理学给自己或别人的行为找借口。
9. 把群体的统计倾向直接套到面前这个具体的人身上。
10. 认为物质能买到喜欢。
11. 以为只要足够努力就能得到任何一个人。
12. 把"承认关系里存在交换"理解成"所以要用交易的方式处理关系"。

## 关于身体与形象（13–24）

13. 只做有氧，从不接触力量训练。
14. 每天都练，从不休息，然后两周后放弃。
15. 体重掉了就以为成功了，却没注意掉的可能主要是肌肉。
16. 靠节食，靠代餐，靠不吃晚饭。
17. 长期睡不到六小时，却指望训练有效果。
18. 花很多钱买潮牌，但衣服不合身。
19. 衣服宽大遮体型，结果显得更糟。
20. 全身超过三种颜色，还带大 Logo。
21. 认为护肤是"女生的事"。
22. 不处理口腔、气味、指甲这些细节。
23. 身高焦虑到影响所有其他方面的行动。
24. 等"练好了再开始"——这个"好"永远不会来。

## 关于金钱与职业（25–31）

25. 在收入不高的时候，花大量时间研究投资技巧。
26. 没有安全垫，全部资金投入高波动的地方。
27. 用分期和借贷维持一个超前的生活方式。
28. 只看收入，不看职业资本的增长。
29. 三年没做过一件"没人要求我做但能写进简历"的事。
30. 把工作当成全部，社交圈只剩下同事。
31. 认为"等我有钱了再说"——钱之后的那些能力，才是真问题。

## 关于情绪与沟通（32–42）

32. 把"情绪稳定"理解成压抑和忍耐。
33. 情绪攒得很满才第一次意识到。
34. 在最生气的两分钟里，把最伤人的话说出去。
35. 用冷暴力代替表达。
36. 说出"你总是""你从不"。
37. 用"你应该懂我"来代替说清楚需求。
38. 别人倾诉时急着给建议。
39. 别人讲话时思考自己接下来要说什么。
40. 对话里不能忍受两秒的沉默。
41. 把外面的情绪带回家。
42. 冲突之后从不修复，任它悬在那里。

## 关于行为与关系（43–50）

43. 单向高投入，然后期待对方自动回应。
44. 被拒绝之后冷暴力、或者到处评价对方。
45. 用含糊的拒绝拖住别人。
46. 接受拒绝之后换一种方式再试一遍。
47. 相信自己能改变一个人的基本性格。
48. 在关系里完全放弃自己的朋友和空间。
49. 把关系当成解决自己空虚的唯一方式。
50. 只研究"怎么被喜欢"，从不研究"自己想成为什么样的人"。

**如果这五十条里你中了超过五条，请不要焦虑——** 这些错误是几乎每个人都犯过的。你要做的不是一次全改，而是从里面挑**三条**，用三个月改掉。然后回来挑另外三条。

# 附录 E · 延伸阅读

下面这些书，分别对应本书的几个支柱。**不要一次全买，按你当下的短板选一本，读完再做下一步。**

## 进化与择偶机制

- 达尔文《人类的由来及性选择》——性选择理论的原始出处。
- 戴维·巴斯《欲望的演化》——跨文化择偶偏好的通俗综述，读它时要连带读它的方法局限。
- 特里弗斯《亲代投资与性选择》（1972 年论文）——这个框架的理论原点。读原始论文，你会对"生存价值/繁殖价值"这两个词有完全不同的理解。

## 身体与状态

- 美国睡眠医学会与睡眠研究学会 2015 年的成人睡眠时长共识声明（公开可查，篇幅很短）——比任何畅销书都更适合作为睡眠的起点。马修·沃克的《我们为什么要睡觉》流传很广，但其中若干数据与结论受到过研究者的公开批评，读时请对照原始文献，不要照单全收。
- 詹姆斯·克利尔《掌控习惯》——如何让训练与作息变成不需要意志力的默认行为。
- 一本可靠的力量训练入门教材（选择有动作分解图、强调标准姿势的那类）。

## 情绪与沟通

- 马歇尔·卢森堡《非暴力沟通》——"事实—感受—需求—请求"四步的源头。
- 约翰·戈特曼《幸福的婚姻》——基于长期观察研究的冲突处理与关系维护，尤其看他关于"修复"的部分。
- 罗兰·米勒《亲密关系》——亲密关系领域的系统教材，比任何网红观点都值得读。

## 依恋与自我

- 阿米尔·莱文、蕾切尔·赫勒《依恋》（Attached）——理解依恋风格如何影响你在关系里的行为。这是通俗读物，"类型"划分是简化版，请当作观察的镜头，而不是诊断。
- 卡罗尔·德韦克《终身成长》——关于"能力可以增长"这一信念如何影响学习与行为。相关干预的效果在后续研究中存在争议，保持适度怀疑即可。
- 埃利奥特·阿伦森《社会性动物》——社会心理学的经典入门，能替你把很多直觉换成可靠的判断。

## 金钱与职业

- 摩根·豪泽尔《金钱心理学》——关于金钱的态度与行为，比技术细节重要得多。
- 一本关于个人现金流与风险管理的入门读物，只要一本，认真读完并执行。

## 关于如何使用这份书单

**读书不等于改变。** 读完之后，请回到附录 B，看看你要修的那一项，然后用附录 A 的方式把它变成每天的动作。

**真正让你变化的，从来不是你读过的书，而是你合上书之后做的第一件事。**
