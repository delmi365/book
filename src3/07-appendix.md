# 附录 B 万能句式库

这些是**结构**，不是台词。把里面的空白换成你自己的内容，就能用在绝大多数场景里。

## 开场与重启

- **共同场景切入**："刚才那个××，你听明白了吗？我有点没跟上。"
- **共同记忆重启**："刚看到××，想起你上次说想去，去成了吗？"
- **请教式**："你资料里写××，我猜你是同行——你是做哪块的？"
- **分享式**："刚在××看到这个，想到你上次说喜欢，给你看看。"

## 把话题接下去

- **往外延**："（她说的那件事）具体是什么样的？"
- **往内收**："你是喜欢××本身，还是喜欢那时候的感觉？"
- **自曝换提问**："我前两年也这样——你那会儿是怎么熬过来的？"
- **回应情绪**："那段时间你应该挺累的吧？"
- **放大好消息**："真的吗！那你怎么庆祝的？"

## 邀约

- **标准式**："（具体时间）＋（具体地点）＋（具体的事），不方便也直说。"
- **降低门槛**："顺路喝一杯，四十分钟就走。"
- **接上次的线索**："你说想看那个展，周日最后一天，要不要去？"
- **给截止点**："那你看情况，周四前告诉我一声就行。"

## 表达好感（不要求回应）

- "我挺喜欢跟你待在一起的。"
- "最近见你的日子我会比较期待。"
- "跟你聊天很省力，我喜欢这种感觉。"
- "今天那个××（具体瞬间）我还挺意外的。"

## 确认与同意

- "我可以牵你吗？"
- "现在这个节奏你舒服吗？"
- "我们慢一点，不着急。"
- "你想停下来就说一声。"
- "我们之前都做过检查吗？我想确认一下。"

## 拒绝（清楚、简短、不解释）

- "谢谢，不过那天我有安排了。"
- "这个我现在不想，我们慢慢来。"
- "我不太想在还不熟的时候说这个。"
- "不行。"（＋重复，不解释）
- "请停止联系我。再联系我会报警。"

## 冲突与修复

- **叫停**："我现在有点上头，怕说出不该说的。给我二十分钟。"
- **我字句**："我刚才觉得被忽略了。"
- **问具体**："是哪一件事让你这么觉得？"
- **有效道歉**："我错在××。这让你觉得××。下次我会××。"
- **定方案**："下次遇到这种情况，我们怎么处理？"

## 边界

- "这个我不太舒服，请不要这样。"
- "我能做到的是××，你看行不行？"
- "我每周想留一晚上跟朋友出去，这个时间对我挺重要的。"
- "我不接受用关系来要求我做这件事。"

# 附录 C 21 天对话练习

说话这件事，和健身一样：**看懂了不算，练过才算。** 下面 21 天，每天一件事，挑一天里真实发生的一次对话来练。

| 天 | 练习内容 | 自查 |
| --- | --- | --- |
| 1 | 主动发起一次对话，开场带上**具体的内容**（不是"在干嘛"） | 对方接得上是／否 |
| 2 | 在一段对话里，**用自曝换一次提问** | 我有没有先给出自己的东西 |
| 3 | 对方说一件事，你只做**回应情绪**，不给建议 | 我忍住建议了吗 |
| 4 | 对话还热的时候，由你**主动结束**一次 | 我给了理由吗 |
| 5 | 发一条消息后**不追加**，等对方回 | 我等住了吗 |
| 6 | 把一句抽象的夸奖改成**具体的瞬间** | 说得出那个瞬间吗 |
| 7 | 复盘前六天：哪一次对方的回应明显变长了 | 记下来 |
| 8 | 发出一次**具体的邀约**（时间＋地点＋事由） | 三要素齐了吗 |
| 9 | 遇到"看情况"，给它一个**截止点**，不再追问 | 我追问了吗 |
| 10 | 主动**转移一次话题**，并用了过渡词 | 过渡自然吗 |
| 11 | 一次对话里，**让对方多说一点**（你问得比说得少） | 比例如何 |
| 12 | 对方抱怨时，**先共情，再判断要不要给方案** | 顺序对了吗 |
| 13 | 说一次**不需要对方回应的好感** | 我要求回应了吗 |
| 14 | 复盘第二周：有没有一次对方主动找你 | 有／没有 |
| 15 | **拒绝一件你不想做的事**，简短、不解释 | 我解释了吗 |
| 16 | 提一个**具体的、正向的需求** | 是"我希望"还是"你从来不" |
| 17 | 说一次**边界**："这个我不太舒服" | 说出口了吗 |
| 18 | 在一段有分歧的对话里，全部用**"我"字句** | 有没有冒出"你总是" |
| 19 | 做一次**完整的道歉**（错在哪＋影响＋下次怎么做） | 三样齐了吗 |
| 20 | 主动**叫停一次**快要升级的对话，并承诺回来 | 我回来兑现了吗 |
| 21 | 通读全书，写下**你自己最常犯的一条**，作为下个月的靶子 | 只写一条 |

**三条纪律：**

1. **只练真实的对话。** 脑子里模拟的不算——真实对话才有反馈。
2. **每天只改一件事。** 试图一次改三样，结果是一样都改不了。
3. **看对方的反应，不看自己的表现。** 你觉得自己说得漂不漂亮不重要；**她接得上是唯一的标准。**
