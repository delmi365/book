# 附录 C 术语替换对照表

原素材使用的是一套 PUA 行话。这套词不是中性的——它预设了"交往是一场可以拆解、可以推进、可以攻克的流程"。本书正文已全部替换，这里列出对照，方便你读原始素材时自己换算。

| 原文术语 | 含义 | 本书用词 |
| --- | --- | --- |
| 把妹 / 泡学 / 泡妞 | 追求、交往 | 认识人、交往、建立亲密关系 |
| TD / 推倒 / 拿下 / 搞定 / 变现 | 发生性关系 | 发生亲密关系（"变现"这类把亲密当交易的说法直接删除） |
| 进挪（kino） | 逐步肢体接触 | 亲密接触的推进 |
| 窗口 / 兴趣指标（IOI） | 对方释放的好感信号 | 好感信号（但不得用它替代确认） |
| DHV / DLV | 高/低价值展示 | 展示自己的长处 / 自我贬低 |
| ASD（反荡妇机制） | 女性因顾虑社会评价而抗拒 | 不使用；改写为"对方的社会顾虑与安全感需求" |
| LMR（最后一刻反抗） | 亲密前的犹豫 | 不使用；改写为"犹豫——意味着停下来确认" |
| 服从性测试 | 提出小要求观察对方是否顺从 | 不使用；改写为"小的、可被拒绝的邀请" |
| 废物测试（shit test） | 对方的试探 | 对方的试探与安全感确认 |
| 打压（neg） | 贬低对方以削弱其自信 | 不使用（见第 25 章） |
| 推拉 | 忽冷忽热制造情绪落差 | 不使用（见第 25 章） |
| 猫绳理论 | 给甜头再撤回，让对方追逐 | 不使用（见第 25 章） |
| 展示面 | 社交软件个人主页 | 社交资料（可用） |
| 框架 | 相处中的原则与底线 | 边界与态度（保留，已在第 3 章给出通俗定义） |
| 炮友 / 情人 / 供养者 | 关系类型分类 | 删除；"长期/短期"改为"以结婚为导向 / 不以结婚为导向" |
| 资源 / 目标 / 拿下 | 指代人 | 一律替换；不把人称为资源 |
| 泡学中毒 | 沉迷技巧而失去真诚 | 保留为批判概念（第 6 章） |
