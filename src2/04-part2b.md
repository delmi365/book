# 第十章 聊天的禁忌清单

这一章是把原素材里散落在十几篇短文中的"雷区"合并成一张清单。建议每月扫一遍，逐项自查。

## 沟通行为类

| 序号 | 禁忌 | 说明 |
| --- | --- | --- |
| 1 | 对方没回就追加消息 | 尤其不要当天内连续追问 |
| 2 | 连环发问、查户口式提问 | 姓名、工作、哪里人一口气问完 |
| 3 | 一次发一大段 | 一次 1–2 条即可 |
| 4 | 滥用语气助词和表情 | 对方没发表情前尽量少发 |
| 5 | 回复频率严重失衡 | 对方半天回你，你秒连三条 |
| 6 | 说话套路化、官方化、学术化 | 不接地气 |
| 7 | 强行续话题 | 见第九章 |
| 8 | 单方面持续提供话题 | 主动提供两三次为上限 |
| 9 | 一味认同对方观点 | "一直附和才减分，说错不减分" |
| 10 | 主动聊严肃或伤感话题 | 关系没到那个阶段 |
| 11 | 主动聊过往情感经历 | 对方主动问也点到为止 |
| 12 | 触碰外形雷区 | 身高、体重、外形、年龄 |
| 13 | 早晚安打卡 | 普通关系阶段显得刻板，也会给对方压力 |
| 14 | 问"在吗" | 要聊就直接聊 |
| 15 | 问"你觉得我这个人怎么样" | 把判断权完全交出去 |
| 16 | 见面后故作冷淡、故意延迟 | 想联系就联系，不要演 |

## 心态与姿态类

| 序号 | 禁忌 | 说明 |
| --- | --- | --- |
| 17 | 献殷勤、讨好、迎合 | 见第二章 |
| 18 | 死缠烂打 | 见第二章 |
| 19 | 单方面的物质付出 | 充话费、发红包、叫外卖、转账、代付链接 |
| 20 | 用表白推进关系 | 见第四章 |
| 21 | 试图用金钱换感情 | 原素材那句很准："即使利用金钱产生了感情，那她也只是跟金钱产生了感情，不是和你" |
| 22 | 反复展示自己的长处 | 十句里一两句就够，"说多了就是装" |
| 23 | 与对方互怼、争吵 | 观点不同可以表达，不必争输赢 |
| 24 | 早早就暴露全部，或完全不表达 | 两端都不可取 |

## 约会现场补充

25. 一方一直讲，另一方插不上话
26. 表情过于夸张、语速过快或刻意放慢
27. 讲自己现在很挫的事（童年趣事可以，现在的糗事减分）
28. 点菜、选地点时完全没有主见（正确做法：先问忌口和想法，**然后自己拿主意**）
29. 迟迟不推进，掉进"友谊区"

## 关于"打压"

原素材里出现过"打压"这个词（故意贬低对方以压低其"分数"）。**这一条我整体删除了。**

理由很简单：在对方没有不尊重你的情况下，单方面贬低对方是极小家子气的行为，它唯一的用处是制造不安全感。原素材自己也说了"对方没有不尊重你时单方面打压是小家子气"。

需要保留的只有一件事：**当对方真的越界、不尊重你的时候，表达你的态度。** 这不是打压，这是边界。

# 第十一章 不回消息、电话与后续

## 对方不回消息：先分类，再行动

**常见的原因（不分先后）：**

1. **在忙**：工作、开会、上课、加班、玩游戏、看剧、困了、心情不好。
2. **你发的东西让人不好接**：太长、太多、太讨好、太有侵略性，对方不知道怎么回。
3. **兴趣不足**：用沉默表示拒绝。

原素材里有一句"她绝对是看到了，就是故意不回"——这种归因我删掉了。它除了让你生气，没有任何用处。

**正确的动作：**

| 情况 | 做法 |
| --- | --- |
| 当天没回 | 当天不再发。过两天再聊（反馈一般的隔一天，聊得好的第二天继续） |
| 多次不回 | 不再追问，把时间转投给别处 |
| 想确认 | 最多一次，用陈述句而不是质问："上次说的那家店，你要是有兴趣我们改天去，没兴趣也没事" |

**明确不要做的事：** 追问"怎么了""为什么不理我""你干嘛去了"；发笑话逗她；指责；自我贬低。

**一条重要的心态**：不回应本身就是一种信息。在没有其他解释、且持续多次的情况下，通常可以理解为兴趣不足。**这时候最体面的做法是停下，而不是追问为什么。**

## 电话：什么时候打、怎么打

原素材关于电话的部分很实用：

- **时机**：一般是对方打给你，或者对方希望你打给她。除了邀约，通常不需要你主动打。
- **定位**："润滑剂式"的聊天——拉家常、把微信上聊过的再回顾一遍，目的是培养安全感、熟悉感、舒适感。
- **讲故事要带细节和感情**。原素材给了一个很好的例子：聊到宠物时，"我之前也养过一只狗，每次回家它都跑到我脚下转啊转，做错事打它时看到它眼泪汪汪的样子，心都软了"——这种细节比一句"我很有爱心"有力得多。
- **谈感情时多从对方的角度说**，用陈述句，少说"你应该这样、那样不对"。
- **顺带邀约**：聊得愉快时自然提出，可以说大概去哪、对方喜欢吃什么，细节留到见面再说。
- **时长**：没聊到推进或邀约的，十几分钟即可；聊得不错的半小时左右收。**不要煲几个小时。**

## 后续：见面之后的联系

- **见面当天就发消息**（第 8 章已讲）。
- **至少一周见一次**：作为早期的经验值，一周见一次比较利于维持熟悉感，间隔过长，热度容易散掉。
- **保持一定频率的付出、关心在线**：不用天天聊，但要让对方知道你在。

## 精力分配：80/20

原素材里有一个很实用的时间分配方法，去掉"资源""养鱼"这类词之后是这样：

| 对方的反馈 | 投入 |
| --- | --- |
| 积极：持续有热度、愿意聊、约会不难 | 每天聊，几天内推进与邀约。**投入 80% 的时间** |
| 普通：不冷不热、有时不回 | 不必每天聊，观察变化。**投入 20%** |
| 冷淡：敷衍、只发表情 | 放下，极少量时间 |
| 只索取不付出、要红包转账、骗吃骗喝 | **停止投入** |

这套分配的价值在于：**它把你的注意力从"那个不回我消息的人"身上，转移到"那个愿意和我聊天的人"身上。** 而这两者之间的差别，往往决定了你这一段时间过得怎么样。

# 第十二章 邀约：提出、被拒、止损

## 两步走：模糊邀约 → 确定性邀约

原素材里的这个方法非常实用：

**第一步，模糊邀约。** 在聊天中自然抛出：

> "空了我们见见啊。""有空一起喝点东西。""那家新开的店，改天去试试。"

要求是：**大大方方直接说**，不要绕弯、不要打哑谜让对方猜。

**第二步，确定性邀约。** 模糊邀约之后，几天到一周内落实：

- **提前 2–3 天**问对方什么时候有空；
- 必须落实到**具体时间和地点**——"周六下午三点半，万达广场星巴克门口"，而不是"下午"这种大范围；
- 抛项目比抛问题有效：不说"要不要出来玩"，而说"那我们去那家新开的 XX 试试"。

**不必等到聊得足够暧昧才邀约。** 对比较传统、保守的对象，没有暧昧铺垫也可以直接提出见面。

## 被拒绝时：先分辨是拒绝还是犹豫

| 类型 | 典型措辞 | 处理 |
| --- | --- | --- |
| 真实拒绝 | "我现在没空""再说""我不跟不太熟的人吃饭"——语气平静、低情绪、无替代方案 | **不追问理由，不纠缠。** 退回继续相处，或者体面退出 |
| 犹豫 | "要不再看看吧""会不会太快了"——语气更软，仍在观望 | 可以降低门槛再提**一次**：换个时间、换个项目、缩短时长；若仍含糊，就当作婉拒 |
| 客观原因 | 身体不适、加班、开会——**并主动提出改期** | 直接改时间，不算拒绝 |

**关于真实拒绝，原素材里有一句我很认同的话**：不用去研究背后的原因，"她拒绝是真实的，这就够了"。追问原因除了自我消耗，得不到任何东西。

## 止损：三次原则

原素材里有一个"333 原则"，去掉其中的"过滤掉她"这类说法之后，是一个很好的止损线：

- **三次邀约都不出来**（且没有客观原因）；
- **多次约会，亲密度毫无推进**；
- **长期只有单向投入，对方没有任何形式的回馈**。

出现以上任何一种，正确的做法是：**尊重对方的选择，把精力转回自己的生活。**

注意措辞的区别：原素材写的是"过滤掉她"，我改为**"体面退出"**。前者是把对方当成一个被淘汰的选项，后者是承认一个事实——她不想，那就不想。

## 邀约的安全原则

这一条原素材没有，但我必须补：**见面地点由你选，选你熟悉、热闹、市中心的地方，或者两人之间的中间地带；不要去对方指定的、你陌生的、偏僻的地方。**

理由在第 24 章会展开：饭托、酒托、仙人跳这类骗局，第一步永远是"把你引到一个你陌生的地方"。而真有兴趣的人，能接受你选一个热闹的地方。

## 一个常被问的问题：要不要表白才能约出来

不需要。**邀约本身就是最自然的推进。**

原素材里那句"聊天的最终目的是为了邀约，我们要把关系落实到实处"，去掉行话之后就是这个意思：线上的一切都只是铺垫，真正的判断只在见面时发生。
