# 三本书 · Delmi 编著

三本关于亲密关系的实操读本，**全部为在线阅读 HTML 版**（不含 EPUB / Markdown 文件）。

| 书名 | 副标题 | 在线阅读 |
| --- | --- | --- |
| 《价值交换》 | 亲密关系中的生存价值与繁殖价值 | [HTML](output/价值交换_生存价值与繁殖价值_电子书.html) |
| 《不套路》 | 从认识到长期关系的实操手册 | [HTML](output/不套路_从认识到长期关系的实操手册_电子书.html) |
| 《把话说清楚》 | 关系场景对话与回应手册 | [HTML](output/把话说清楚_关系场景对话与回应手册_电子书.html) |

## 在线阅读

直接用浏览器打开 `index.html`（本仓库首页），点书名即可阅读；每本书也可单独打开
`output/` 下的 HTML 文件。「打印 / 存 PDF」可离线保存。

## 目录结构

```
三本书/
├── index.html              # 书籍首页（点开即读）
├── output/                 # 成品：每本书一个 HTML 文件
│   ├── 价值交换_生存价值与繁殖价值_电子书.html
│   ├── 不套路_从认识到长期关系的实操手册_电子书.html
│   └── 把话说清楚_关系场景对话与回应手册_电子书.html
├── src/  src2/  src3/      # 三本书的 Markdown 源稿（改这里重出书）
└── build.py  build2.py  build3.py   # 构建脚本（无第三方依赖，仅用 Python 标准库）
```

## 改稿重出

1. 编辑 `src/`（或 `src2/`、`src3/`）里的 Markdown；
2. 在项目目录下运行：

```bash
python build.py      # 出《价值交换》
python build2.py     # 出《不套路》
python build3.py     # 出《把话说清楚》
```

生成的 HTML 会写入 `output/`，覆盖旧文件。

> 说明：本系列最初基于读者提供的一份网络素材（约 25 万字）整理，经去重、结构重建、
> 内容改写与补充而成。原素材中用于绕开对方同意、制造情绪控制的表述已全部删除；
> 涉及拒绝、边界与不适场景的回应方式，为编者补充。
